# Бюджет КЗ

Личный трекер расходов в виде веб-приложения (PWA) для iPhone. Здесь только код оболочки, без данных.

- Данные (траты и бюджет по категориям) хранятся в отдельном **приватном** репозитории в папке `data/`
  (`expenses-<год>.json`, `categories.json`) и читаются/пишутся через GitHub API с устройства.
- Токен доступа (fine-grained PAT с правом Contents: Read and write только на репозиторий с данными) вводится один раз
  в самом приложении и хранится только в браузере телефона.

Установка на iPhone: открыть сайт в Safari → «Поделиться» → «На экран “Домой”».
