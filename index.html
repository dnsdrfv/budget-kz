Хранилище данных

Записи хранятся в вашем приватном репозитории на GitHub. Приложение читает и пишет их по токену, который остаётся только на этом устройстве.

Как создать токен
  1. На github.com: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → выбрать репозиторий с данными.
  3. Permissions → Repository permissions → Contents: Read and write. Остальное не нужно.
  4. Expiration: максимальный срок. Нажать Generate и вставить токен сюда.

Чтобы открывать как приложение: в Safari нажмите «Поделиться» → «На экран “Домой”».
